# Pokémon Card Pack Simulator

## Overview
The Pokémon Card Pack Simulator is a web application that allows users to simulate opening original Pokémon card packs. Users can log in to their accounts, open packs, and save their card collections. The application leverages Firebase for authentication and storage, ensuring a seamless user experience.

## Features
- **User Authentication**: Users can register and log in using their Google accounts.
- **Card Pack Simulation**: Open packs that contain a random selection of cards based on rarity.
- **Card Collection**: Save and view your collected cards.
- **Firebase Integration**: Utilizes Firebase Storage for image hosting and Firestore for data management.

## Technologies Used
- **Frontend**: JavaScript, HTML, CSS
- **Backend**: Firebase (Firestore, Storage, Authentication)
- **Build Tools**: NPM

## Usage
 - After logging in with your Google account, click the "Open Pack" button to receive a random selection of Pokémon cards.
- The cards will be displayed on the screen, and you can save them to your collection for future reference.
